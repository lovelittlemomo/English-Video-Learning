# English Video Learning - iOS/macOS 应用使用指南

一个帮助你通过视频轻松学习英文单词的 Mac 和 iPad 应用。

## 📥 第一步：安装 Xcode（开发环境）

### 方法 1：通过 App Store 安装（推荐）

1. 打开 Mac 上的 **App Store**
2. 在搜索框中输入 `Xcode`
3. 点击"获取"或"安装"
4. 输入 Apple ID 密码完成安装
5. 安装完成后，Xcode 会自动添加到"应用程序"文件夹

> **提示**：Xcode 文件较大（约 12GB），建议使用 Wi-Fi 下载，可能需要 30 分钟以上。

### 方法 2：从 Apple 官网下载

1. 访问 [developer.apple.com/download](https://developer.apple.com/download)
2. 登录 Apple ID
3. 搜索 Xcode
4. 下载最新版本
5. 下载完成后，双击 `.xip` 文件解压
6. 将解压出的 Xcode 应用移动到"应用程序"文件夹

## 🚀 第二步：获取项目代码

有两种方式获取这个项目：

### 方式 A：克隆 GitHub 仓库（推荐新手）

1. 打开终端（或在 Finder 中使用"前往"→"实用程序"→"终端"）
2. 执行以下命令：

```bash
git clone https://github.com/lovelittlemomo/English-Video-Learning.git
cd English-Video-Learning
```

3. 等待下载完成

### 方式 B：直接下载 ZIP（最简单）

1. 访问 [GitHub 仓库](https://github.com/lovelittlemomo/English-Video-Learning)
2. 点击绿色的"<> Code"按钮
3. 选择"Download ZIP"
4. 等待下载完成后，双击解压文件夹

## 🛠️ 第三步：在 Xcode 中打开项目

1. 打开 Xcode 应用程序
2. 选择"File" → "Open"（或按 Cmd + O）
3. 导航到你下载的 `English-Video-Learning` 文件夹
4. 选择文件夹，点击"Open"

> **注意**：
> - 首次打开项目时，Xcode 会自动下载必要的依赖项，可能需要几分钟
> - 左侧会看到项目结构树，包含 App、Views、Models 等文件夹

## ▶️ 第四步：运行应用

### 在 Mac 上运行

1. 在 Xcode 窗口顶部，选择目标设备
2. 找到"Scheme"下拉菜单（默认显示项目名称）
3. 点击右侧的设备选择器，选择"My Mac"或"My Mac (Rosetta)"
4. 按下 **Cmd + R** 或点击"Run"按钮（三角形播放按钮）
5. Xcode 会编译项目（首次可能需要 1-2 分钟）
6. 成功后，应用会自动启动

### 在 iPad 模拟器上运行

1. 在 Xcode 窗口顶部的设备选择器，点击"iPhone" 或 "iPad"
2. 选择一个 iPad 模拟器（例如"iPad Pro (12.9-inch)"）
3. 按下 **Cmd + R** 运行
4. 模拟器会启动，应用在其中运行

## 📚 使用指南

### 主界面选项卡说明

应用分为 6 个主要功能区，顶部有标签页切换：

#### 1️⃣ 视频标签页 📹

**功能**：导入和管理学习视频

**使用步骤**：
- 点击"导入视频"按钮
- 在文件浏览器中选择你的视频文件（支持 MP4、MOV 等格式）
- 视频导入后，会显示：
  - 视频标题（文件名）
  - 视频播放区域（当前是预览占位符）
  - 识别出的英文句子（从视频中提取）

**提示**：
- 建议使用 10-30 分钟的学习视频
- 视频应该包含英文对话或讲解

#### 2️⃣ 单词标签页 📖

**功能**：查看所有学过的单词

**使用步骤**：
- 显示完整的单词列表
- 点击任何单词进入"单词详情"页面
- 在详情页可以：
  - 查看中文意思
  - 查看例句
  - 点击"播放发音"听英文发音
  - 查看你的笔记

**���作**：
- 点击单词右侧的圆圈图标，可标记为"已掌握"（变成绿色打勾）
- 点击右上角的"+"按钮可手动添加新单词

#### 3️⃣ 生词本标签页 📕

**功能**：管理需要复习的生词

**使用步骤**：
- 显示所有需要复习的单词（复习次数 > 0 的单词）
- 类似于"单词"页面，可以查看详情和笔记
- 这里的单词是你需要重点掌握的

**提示**：
- 经常复习生词本中的单词可以加深印象
- 一旦掌握了单词，可以在"单词"页面标记为已掌握

#### 4️⃣ 闪卡标签页 🎴

**功能**：使用闪卡游戏式复习单词

**使用步骤**：
1. 进入闪卡页面
2. 屏幕中央显示一张大卡片，上面是英文单词
3. **点击卡片翻转**，查看中文意思和例句
4. 根据是否掌握，选择：
   - "再看一次" - 这个单词继续留在复习列表
   - "我知道了" - 标记为已掌握，进入下一个单词
5. 循环复习直到没有单词

**学习技巧**：
- 闪卡模式最适合短期高效复习
- 每次学习 10-20 张卡片效果最好
- 重复多次可以加强记忆

#### 5️⃣ 进度标签页 📊

**功能**：查看学习统计和进度

**内容**：
- 今日学习单词数
- 复习进度百分比
- 学习建议和技巧
- 本周学习排行

**用途**：
- 了解学习进度
- 获取学习建议
- 保持学习动力

#### 6️⃣ 设置标签页 ⚙️

**功能**：应用配置和数据管理

**选项**：
- 自动保存笔记（开/关）
- 自动播放发音（开/关）
- 启用复习提醒（开/关）
- 导出生词本
- 清空复习记录

## 💡 完整学习流程示例

### 场景：你看了一个英文视频，想学习其中的单词

**步骤**：

1. **导入视频**
   - 点击"视频"标签页
   - 点击"导入视频"按钮
   - 选择你下载的英文视频文件

2. **查看识别的单词**
   - 视频导入后，下方会显示"识别出的单词"
   - 这些是从视频文本中提取的英文单词

3. **进入单词表查看详情**
   - 点击"单词"标签页
   - 点击某个单词（例如 "curious"）
   - 在弹出的"单词详情"页面可以：
     - 点击"播放发音"听发音
     - 查看例句理解用法
     - 点击"保存笔记"记录学习心得

4. **使用闪卡复习**
   - 点击"闪卡"标签页
   - 依次看单词→点击翻转看意思→选择掌握程度
   - 重复直到掌握所有单词

5. **查看学习进度**
   - 点击"进度"标签页
   - 了解今天学了多少单词，复习进度如何

6. **管理生词本**
   - 点击"生词本"标签页
   - 这里显示所有需要重点复习的单词
   - 每周重复复习一次

## 🎯 学习建议

### 黄金学习节奏

```
第 1 天：学习 5-10 个新单词（通过视频导入）
      ↓
第 2-3 天：用闪卡复习这些单词 2-3 次
      ↓
第 4-7 天：每天复习一次，确保长期记忆
      ↓
第 8 天以后：定期复习，不定期加入新单词
```

### 每天学习时间安排

- **导入视频**：5 分钟
- **查看单词和发音**：10 分钟
- **闪卡复习**：10 分钟
- **总计**：25 分钟/天

### 记笔记建议

在"单词详情"页面记笔记时，建议记录：

```
词性：动词/名词/形容词等
发音：单词的发音方式
近义词：相似意思的其他单词
常用搭配：这个单词常与哪些词组合
个人记忆法：帮助自己记住这个单词的方法
```

## 🔧 常见问题

### Q: 如何更换视频？

**A**: 在"视频"标签页再次点击"导入视频"，选择新文件即可替换。

### Q: 怎样导出我的生词本？

**A**: 进入"设置"标签页，点击"导出生词本"，选择保存位置。

### Q: 如何清空所有学习记录？

**A**: 进入"设置"标签页，点击"清空复习记录"。系统会提示确认。

### Q: 为什么视频导入后看不到识别的单词？

**A**: 当前版本使用示例单词。未来版本会自动通过语音识别提取视频中的英文。

### Q: 能在 iPad 和 Mac 之间同步数据吗？

**A**: 当前版本数据保存在本地。未来版本会加入云同步功能。
